# SubNautika Code

This folder contains the game's reusable logic and generation systems.

Planned systems include:

- Cloud rendering and movement
- Terrain generation
- Ocean/world generation logic
- Resource generation
- Creature spawning
- Environmental effects
- Future procedural world systems

## Structure

`World Preset/` is for world configuration and presentation presets.

`Systems/` is for game-facing pages and gameplay systems.

`code/` is for reusable JavaScript logic that those systems can call.
